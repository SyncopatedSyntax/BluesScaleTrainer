# Blues Scale Trainer

Part of [Fretworks](https://fretworks.vercel.app) — live at
[fretworks.vercel.app/blues](https://fretworks.vercel.app/blues/).

Learn the minor and major blues scales in five boxes and the five joins between
them, compare them with the major scale, natural minor and both pentatonics, and
hear what the blue note does over a 12-bar. Spaced-repetition practice with
shape, blue-note and comparison drills.

```
npm install
npm run dev      # http://localhost:5187/blues/
npm run verify   # correctness gate — every shape re-derived from first principles
npm run build
```

See `CLAUDE.md` for how it is built and why.
